Förbered och ladda hem test programmet
	Skapa rfid mappen:
		mkdir rfid
	Hoppa in i mappen:
		cd rfid
	Skapa en virtual enviroment för att installera med pip (tar lång tid, tålamod)
		python -m venv rfid
	Hoppa in i virtual enviroment
		source rfid/bin/activate
	Installera alla paket som behövs (tar lång tid, tålamod)
		pip install spidev mfrc522
	Ladda hem test skriptet
		wget https://raw.githubusercontent.com/Storsjogymnasiet/Solutions-and-files/refs/heads/main/RFID/tester.py
	testa programmet
		python tester.py

Koppla RFID scanner till raspberry
	OBS! Koppla försiktigt, dubbelkolla innan ni kopplar i.
		koppla INTE något i 5v pin !!!
	Dubbel OBS! stäng av och koppla ur raspberry pi innan ni börjar!
	
    SDA connects to Pin 24.
    SCK connects to Pin 23.
    MOSI connects to Pin 19.
    MISO connects to Pin 21.
	IRQ connects to nothing.
    GND connects to Pin 6.
    RST connects to Pin 22.
    3.3v connects to Pin 1.
